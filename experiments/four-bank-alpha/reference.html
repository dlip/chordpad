Chordpad layout

Four-bank layout for Linux and Android. Pause/resume: A+B+X+Y; release all controls.

Hold the bank bumpers, or add them within 100 ms after pressing a thumb button, before that thumb releases. Tap and release to type; hold 300 ms to repeat. No letter uses a diagonal or two face buttons.

Hold either stick direction before starting a stroke; L2 adds Shift. Meta = Super / Command. Stick-click shortcuts ignore held modifiers.

Without sticks: tap an unused R1+R2 pair for face modifiers, or L1+L2 for D-pad modifiers. Hold a mirrored direction above (Y/B/A/X = ↑/→/↓/←), including adjacent pairs, across keys or mouse clicks; release to exit. Repeat the tap to cancel. Holding a pair with typing keeps its layer, including R1+R2 navigation.

ControlBehaviour
R1 / L1 aloneSpace / Backspace. Hold alone 300 ms to repeat every 80 ms; release stops.
Late bumpersOnly the newest stroke accepts additions, for 100 ms.
Bank freezesOn next thumb press, thumb release, or deadline; bumper releases preserve it.
L2 tap ≤250 msShift for the next key; tap ≤250 ms again to cancel. Hold L2 for momentary Shift.
Hold any outputRepeat after 300 ms, every 80 ms. Release stops without an extra tap.
Hold R1 + R2Navigation above. Add L1 for editing/media. Consumes R1's Space tap.
R2 tapsNumbers → functions → off. Next key clears selection. Taps ≤250 ms; no gap limit.
Start / SelectEnter / Escape.

First outputs retain press order; small symbols need Shift. Pause/reset clears one-shot selections.
Linux: held modifiers also work with mouse clicks. Android: Shift-click/tap selects text; global mouse modifiers need the ADB helper.
